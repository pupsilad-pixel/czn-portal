## 🎯 О проекте

Это **демонстрационный прототип** портала Центра занятости населения Республики Татарстан, разработанный для презентации заказчику. Проект создан с фокусом на качество интерфейса и UX, без backend-логики и реальных API.

### Ключевые особенности

- ✨ **Современный дизайн** — минималистичный интерфейс в стиле Госуслуг, Т-Банка
- 🎨 **Фирменный стиль** — цветовая палитра на основе брендбука ЦЗН РТ
- 📱 **Полная адаптивность** — корректное отображение на всех устройствах
- ⚡ **Плавные анимации** — Framer Motion для улучшения UX
- 🏗️ **Чистая архитектура** — Feature-Sliced Design
- 🧩 **Компонентный подход** — переиспользуемые UI-компоненты
- 📊 **Реалистичные данные** — качественные моковые данные для демонстрации

## 🚀 Технологический стек

### Core
- **Next.js 15** — App Router, Server Components
- **React 19** — последняя версия
- **TypeScript** — строгая типизация

### Стилизация
- **TailwindCSS** — utility-first CSS
- **shadcn/ui** — готовые компоненты
- **Framer Motion** — анимации
- **Lucide React** — иконки

### Дополнительно
- **Embla Carousel** — карусель баннеров
- **class-variance-authority** — варианты стилей
- **clsx + tailwind-merge** — композиция классов

## 📦 Установка и запуск

### Требования
- Node.js 18+ 
- npm или yarn

### Установка зависимостей

```bash
npm install
```

### Запуск development-сервера

```bash
npm run dev
```

Проект будет доступен по адресу: [http://localhost:3000](http://localhost:3000)

### Production build

```bash
npm run build
npm start
```

## 🎨 Дизайн-система

### Цветовая палитра

- **Основной зелёный**: `#0050AA` — фирменный цвет ЦЗН
- **Акцентный оранжевый**: `#E65028` — для выделения
- **Фоны**: `#F4F7FB`, `#E8EFF8` — нейтральные светлые
- **Текст**: `#0A1628` (основной), `#3A5070` (вторичный), `#7A96B4` (приглушённый)

### Типографика

- Шрифт: **Inter** (Google Fonts)
- Заголовки: `font-bold`, размеры от `text-2xl` до `text-6xl`
- Основной текст: `text-sm` до `text-base`

### Скругления

- Карточки и блоки: `rounded-2xl` (16px)
- Кнопки: `rounded-xl` (12px)
- Малые элементы: `rounded-lg` (8px)

### Тени

- Карточки: `shadow-sm`, при hover `shadow-lg`
- Модальные окна: `shadow-xl`

- ✅ **Подбор персонала** (`/recruitment`) — база резюме
- ✅ **Государственные услуги** (`/services`) — полный каталог услуг
- ✅ **Новости** (`/news`) — список + детальная страница
- ✅ **Проекты** (`/projects`) — государственные программы
- ✅ **Контакты** (`/contacts`) — офисы, карта, форма обратной связи
- ✅ **Структура ЦЗН** (`/structure`) — руководство и подразделения
- ✅ **FAQ** (`/faq`) — часто задаваемые вопросы

## 🎭 Компоненты

### UI-компоненты (shadcn/ui based)

- `Button` — кнопки с вариантами стилей
- `Card` — карточки контента
- `Badge` — значки и метки
- `Input` — поля ввода
- `Breadcrumbs` — хлебные крошки
- `SectionHeader` — заголовки секций
- `Skeleton` — loading-состояния

### Виджеты

- `Header` — двухуровневый хедер с Mega Menu
- `TopBar` — верхняя панель (контакты, языки, соцсети)
- `MegaMenu` — выпадающая навигация
- `MobileMenu` — мобильное меню
- `Hero` — главный блок с CTA
- `BannerCarousel` — карусель промо-баннеров
- `Footer` — многоуровневый футер

### Карточки

- `NewsCard` — карточка новости
- `EventCard` — карточка события
- `ProjectCard` — карточка проекта
- `VacancyCard` — карточка вакансии
- `ServiceCard` — карточка услуги

## 🎬 Анимации

Проект использует **Framer Motion** для плавных анимаций:

- Fade in на появление элементов
- Slide up для карточек
- Hover-эффекты на кнопках и карточках
- Плавные переходы между состояниями
- Анимированная карусель баннеров

## 📱 Адаптивность

Проект полностью адаптивен для всех устройств:

- **Desktop** — 1280px+ (оптимальный вид)
- **Laptop** — 1024px-1279px
- **Tablet** — 768px-1023px
- **Mobile** — 320px-767px

Используется **Mobile First** подход.

## 🔒 Важные замечания

### Это демо-прототип

- ❌ Нет backend
- ❌ Нет API
- ❌ Нет авторизации
- ❌ Нет базы данных
- ❌ Формы не работают

### Все данные — моковые

Все новости, вакансии, события и другой контент являются демонстрационными заглушками для презентации интерфейса.
